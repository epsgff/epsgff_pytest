# STL 平面摆正

框选一块区域 → 用选中的面拟合一个平面 → 按这个平面的倾斜把整个物体旋转摆正（平面法向转到 +Z）。

## 运行

```bash
pip install -r requirements.txt
python stl_plane_align.py            # 或 python stl_plane_align.py 文件.stl，也可以把 STL 拖进窗口
```

## 用法

1. **打开** STL。
2. 按 **S** 进入框选模式，左键拖一个框选中参考区域（红色）。
   按住 Shift 拖动 = 添加，按住 Ctrl 拖动 = 减去。不在框选模式时左键旋转视图，中键平移，滚轮缩放。
3. 右下角显示选区平面当前的倾斜角。点 **摆正**（或回车），整个物体会绕选区中心旋转，选区平面变水平。
4. **保存**为新的 STL。不满意可以按 **撤销**（Ctrl+Z）。

右侧是**顶视图高度热图**（从正上方看、按 Z 着色），每次摆正或撤销都会自动更新，可以直观看到倾斜是否消除。热图里左键平移、滚轮缩放。

只会选中能看到的那层表面，被挡住的底面、背面不会被选进去。从上往下看着顶面选，摆正后顶面朝上。
